# MultiBeamAI

> 基于 AI Agent 驱动的多波束声纳测深数据自动处理管线  
> Multibeam Sonar Bathymetry Processing Pipeline — Built with AI Agents

## 项目概述

MultiBeamAI 是一套完整的**多波束声纳 S7K 原始数据 → 高精度湖泊水下地形图**的自动化处理系统。项目本身完全由 AI 编程助手驱动开发，从算法设计、代码编写、多语言集成到可视化输出，体现了 AI 辅助科学计算的工程能力。

核心管线：原始 S7K 声纳文件 → MB-System 去噪滤波 → XYZ 点云导出 → Julia 自研两阶段迭代聚类滤波 → 全局离群剔除 → 湖泊边界自动检测 → IDW 空间插值 → R 专业级测深图渲染。

## 核心算法

### 两阶段迭代滤波

**第一阶段：格网内深度间隙聚类**

对每个 1m×1m 格网内的所有波束点，按深度排序后扫描相邻间隙。若深度跨度 < 0.25m（保守阈值，基于 15° 斜坡 1m 水平距离的水深变化推导），直接取均值；否则在间隙处切分为多个深度簇，标记为可疑，移交第二阶段。

**第二阶段：迭代空间一致性校验**

利用海底地形连续的前提假设，对可疑格网查找 3×3 邻域中已解决的格网水深，取均值作为参考值，选择最接近参考值的深度簇。新解决的格网加入已解决池，成为下一轮的邻域参考——这是传播式的，多轮迭代直到收敛。无法推进时兜底取最大簇。

**为什么迭代而非单轮：** 空间一致性是传播式的——格网 A 解决后 B 有了足够邻居，B 解决后 C 也有了……单轮只能解决直接相邻的，漏掉间接相邻的。

### P99 分位数全局离群剔除

对所有格网水深值计算 99% 分位数，一刀切掉超过阈值的尾部离群点。这是对"极端噪声不可能占多数"假设的统计学实现。

### 湖泊边界检测（迭代剥离法）

1. **连通区域标记：** 8-邻域 BFS 对已知格网做连通分量分析
2. **取最大区域：** 噪声形成的小碎片自动被过滤（默认最小 10 格网）
3. **边界追踪：** 贪心追踪闭合多边形轮廓
4. **Douglas-Peucker 简化：** 将边界点压缩为少数关键顶点，ε=1m
5. **剥离：** 射线法判定多边形内部，删除所有内部点
6. 回到步骤 1，直到无剩余有效连通区域

### 迭代 IDW 插值

在边界多边形内，对每个空白且位于多边形内部的格网执行 IDW（反距离加权）插值。初始搜索半径 5 格网，若当前轮无进展则扩大到 1.5 倍，最多 50 格网。最小有效邻居数 = 3。迭代直至填满或达到上限。

## 输出文件说明

| 文件 | 含义 | 用途 |
|------|------|------|
| `gridded_1m_xyz.txt` | MB-System 去噪后格网平均 | 纯硬件端处理结果，基线参考 |
| `gridded_1m_clean.txt` | 两阶段滤波 + P99 剔除 | 去噪后高质量水深数据 |
| `gridded_1m_interpolated.txt` | 边界内 100% 填充 | 无缝地形模型，可直接导入 GIS |
| `gridded_1m_*.png` | 对应数据的可视化地图 | 快速预览/报告配图 |

数据格式：`经度(°E) 纬度(°N) 水深(m)`，Tab 分隔。

## 设计原则

- **纯函数优先：** 核心算法函数无副作用，可独立测试
- **参数集中管理：** 算法阈值在 `01_constants.jl`，运行路径在 `run.jl` 顶部
- **中间产物保留：** 异常点、投票中间结果均保留备查
- **坐标一致性校验：** 插值输出自动验证行列数与输入一致
